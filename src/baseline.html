模型说明 · 这个工具到底算了什么

几何：内壁轮廓 r(z) 由「锥角 / 平底 / 直筒」定义，粉床按研磨度对应的堆积密度反解厚度， 有效过流面积取粉床顶面圆面积 A_bed。

渗流：粉床用 Darcy 达西定律 Q = k·A·ΔP /(μ·L)，滤纸层串联附加阻力， 底孔用孔口堰流 Q = C_d·A_hole·√(2ΔP/ρ)，二者串联求解瞬时流量： a·Q² + b·Q = ρ·g·H。

时序：0.5s 步进模拟闷蒸吸润 → 分段注水 → 存水 → 滴滤全过程，实时输出流速曲线与总时长。

萃取：接触时间驱动的产率模型 EY = 22·(1−e^(−t_eff/70))，按研磨与水温修正， 再由 TDS = 粉量×EY / 出液量 推出杯中浓度。

壁部导水槽：滤纸与杯壁之间的贴合缝隙本身是一条通气道，凸肋 / 铣槽把它从 0.09mm 抬到毫米级。 矩形窄缝电导 G = w·h³ /(12μL)，其压降与流量成正比，等效为串联方程里的线性阻力 b_air——这就是锥形杯「滤纸贴壁形成密闭袋腔、排水时负压抵消水头」的量化表达。 平底杯的铣槽则与细粉层横向汇流并联，降低底部汇流阻力。

已知的简化：未计入咖啡粉层非均匀性、注水冲击与温度沿程衰减； 数值用于设计期横向比较与趋势判断，落在实冲误差范围内。
